# Muhammad Zohaib - Portfolio Website

A modern, fully responsive portfolio website showcasing full-stack development skills and projects.

## 🌐 Live Demo
Visit: [www.muhammadzohaib.site](https://www.muhammadzohaib.site)

## 📋 Features

- **Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- **Dark Mode** - Eye-friendly dark theme with smooth transitions
- **Typing Animation** - Dynamic text effect in the hero section
- **Project Showcase** - Interactive slider and grid display of projects
- **Skills Section** - Organized categorization of technical expertise
- **Contact Form** - WhatsApp integration for quick communication
- **Smooth Scrolling** - Elegant navigation throughout the site
- **Font Awesome Icons** - Professional icon set for services and skills

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Hosting**: GitHub Pages
- **Custom Domain**: www.muhammadzohaib.site
- **Icons**: Font Awesome 6.5.0

## 💻 Local Development

1. **Clone the repository**
   ```bash
   git clone https://github.com/zohaib301/portfolio.git
   cd portfolio
   ```

2. **Open locally**
   - Open `index.html` in your browser, or
   - Use a local server:
     ```bash
     python -m http.server 8000
     # or
     npx http-server
     ```

3. **View at** `http://localhost:8000`

## 🔧 Customization

### Update Content
- Edit `index.html` for content changes
- Modify `style.css` for styling
- Update `app.js` for functionality

### Add Projects
Edit the `projects` array in `app.js`:
```javascript
{
    title: 'Project Name',
    description: 'Project description',
    tags: ['Tech1', 'Tech2'],
    demo: 'https://demo-link.com',
    code: 'https://github-repo-link.com',
    image: 'projects/image.svg'
}
```

## 📤 Deployment

This site is automatically deployed to GitHub Pages whenever you push to the main branch.

### Manual Deployment Steps
1. Make your changes locally
2. Stage changes: `git add .`
3. Commit: `git commit -m "Your message"`
4. Push to GitHub: `git push origin master`
5. GitHub Pages will automatically rebuild your site

**Note**: Updates may take 1-2 minutes to reflect on the live site.
